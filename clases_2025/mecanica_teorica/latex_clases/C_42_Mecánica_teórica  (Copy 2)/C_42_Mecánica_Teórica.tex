\[ \left[ Q_{i},Q_{jJ}  \right] =0 \]

\[ \left[ Q_{i},P_{jJ}  \right] = \delta_{ij} \]

\[ \left[ P_{i},P_{jJ}  \right]  \]



En todos los cálculos de TCI (transformación canónica infinitesimal), $\epsilon$, $\epsilon^{2}=0$, $\epsilon^{3}=0 \quad \ldots$


Tenemos:


\[ \delta{q}_{i} \equiv Q_{i}-q_{i} = \epsilon \frac{\partial G}{\partial p_{i}}  \]


\[ \delta{p_{i}} \equiv P_{i} - p_{i} = - \epsilon \frac{\partial G  }{\partial q_{i}}  \]


\[ G = G(q_{i},p_{i},t)  \]





Tenemos:



\[  K(Q_{k},P_{k},t) = H(q_{j}, p_{j},t) + \epsilon \frac{\partial G}{\partial t}\]


Tenemos por definición de función generatriz de segunda clase:


\[ F_{2} = \sum\limits_{i=1}^{n}  q_{i}p_{i} + \epsilon G(q_{j},p_{i},t) \]


Tenemos:


\[ \partial H = H(Q_{k}, P_{k},t ) - K(Q_{k},P_{k},t)   \]


Tenemos:

\[  \partial H = H(q_{i} +  \epsilon \frac{\partial G}{\partial p_{i}}, p_{k} - \epsilon \frac{\partial G}{\partial q_{k}}, t   )  - H(q_{k},p_{k},t) -\epsilon \frac{\partial G}{\partial t} \]

Hacemos un desarrollo en serie de potencia, desarrollamos alrededor de $0$.

\[ f(x) = f(0) + \left. \frac{df}{dx} \right|_{x=0} x  \]


AHora tenemos:


\[ f(\epsilon) = f(0) + \left. \frac{df}{d\epsilon} \right|_{\epsilon=0}  \]



Tenemos así nosotros:


\[  = H(q_{k}, p_{k},t) + \left.\left[    \frac{ \partial H  }{ \partial ( q_{k} + \epsilon \frac{\partial G}{\partial p_{k}} )  }     \right] \right|_{\epsilon =0}  \epsilon + \left. \left[  \frac{ \partial H }{ \partial (p_{k}-\epsilon \frac{\partial G}{\partial q_{k}}) }      \right] \right|_{\epsilon=0} \epsilon - H(q_{k},p_{k},t) - \epsilon \frac{\partial G}{\partial t}\]

Tenemos nosotros:


\[ \partial H = \left(  \frac{\partial H}{\partial q_{k}} \frac{\partial G}{\partial p_{k}}   \right)  \]

En este problema debemos realizar el desarrollo mecánico completo del sistema:

1. Escribir explícitamente las \textbf{ecuaciones de constricción} que impone la geometría,
   y a partir de ellas determinar el número de \textbf{grados de libertad} del sistema.

2. Definir el \textbf{conjunto de ecuaciones} que describen la configuración en términos
   de las coordenadas generalizadas independientes $q_i$.

3. Construir la \textbf{Lagrangiana}
\[
\mathcal{L}(q,\dot q,t)=T(q,\dot q,t)-V(q,t)
\]
expresando todas las cantidades en función de los $q_i$ y $\dot q_i$.

4. Obtener las \textbf{ecuaciones de Lagrange}
\[
\frac{d}{dt}\!\left(\frac{\partial\mathcal{L}}{\partial\dot q_i}\right)
-\frac{\partial\mathcal{L}}{\partial q_i}=0,
\]
(no es necesario resolverlas explícitamente).

5. Realizar la \textbf{transformación de Legendre} para definir los momentos conjugados
\[
p_i=\frac{\partial\mathcal{L}}{\partial \dot q_i},
\]
y calcular el \textbf{Hamiltoniano} mediante:
\[
H(q,p,t)=\sum_i p_i\dot q_i - \mathcal{L}(q,\dot q,t),
\]
reescribiéndolo únicamente en términos de $(q_i,p_i)$.

6. Escribir las \textbf{ecuaciones de Hamilton}
\[
\dot q_i=\frac{\partial H}{\partial p_i},
\qquad
\dot p_i=-\frac{\partial H}{\partial q_i},
\]
las cuales forman el conjunto completo de ecuaciones de evolución del sistema.

7. Identificar las \textbf{constantes de movimiento} verificando:
   - coordenadas cíclicas $\Rightarrow$ $p_i$ constante.
