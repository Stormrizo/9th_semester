Tenemos:


El moemnto angular $\vec{L} \equiv \vec{r} \times \vec{p} \quad \text{es el generador}$ de rotaciones espaciales.

Vamos a probar que si tenemos:


\[  Q_{i} = q_{i} + \epsilon \frac{ \partial G  }{\partial p_{i}}, \quad G = \vec{L} \cdot z \]



Tenemos:


\[  P_{i} = p_{i} - \epsilon \frac{ \partial G  }{\partial q_{i}} \]


Tenemos

\[ \vec{r}(t) = x(t)\hat{x} + y(t) \hat{y} + z(t)\hat{z} \]


Tenemos:


\[  q_{1} = x; \quad q_{2} = y, \quad q_{3} = z \]


\[ \vec{A} = A_{x} \hat{x} + A_{y} \hat{y} + A_{z} \hat{z} \]

\emph{Las rotaciones vienen determinados por 3 parámetros.} Un cuerpo rígido experimenta una rotación y traslación.


El movimiento más general que va a experimentar un cuerpo rígido es un movimiento de \underline{traslación} y \underline{rotación}.


Tenemos:



El número de grados de libertad que tiene un cuerpo rígido en el espacio es:


\[ n = 3N -\mathcal{K}\]


Anre una rotación en el eje en el eje $x-y$, la componente $z$ no se ve afectada.


Tenemos:


\[ \bar{A}_{x} = A_{x} \cos \phi + A_{y} \sen \phi  \]

Tenemos:


\[ \bar{A}_{y} = -A_{x}\sen\phi + A_{y}\cos\phi  \]


\[\bar{A}_{z} = {A}_{z} \]


Entonces ante una rotación las componente se transforman (no infinitesimal)

Tenemos:


\[  ( \bar{A}_{x}, \bar{A}_{y}, A_{z} ) \]


Entonces tenemos (\underline{rotación infitesimal, hacemos una expansión en serie alrededor del $0$ para $\phi$}).


\[ f(x) \approx \sum\limits_{i=1}^{n} \frac{  f^{(n) }a }{ n!  } (x-a)^{n}    \]


Tomando \[ a=0, \quad \text{cuando hacemos eso se llama \textbf{serie de Mclaurin}} \]


Tenemos:


\textbf{A primer orden} (dado que las transformaciones infinitesimales vamos a trabajr en primer orden en $\epsilon$)


Tenemos:

 \[  \cos \phi = \cos 0 + \left. \frac{d \cos \phi }{ d \phi} \right|_{\phi=0} \phi + \ldots     \]

Tenemos:

\[ \cos \phi = 1 - \left. \sen \phi \right|_{\phi=0} \phi\]

\[ \approx 1 \]



Tenemos:


\[   \sen \phi = \sen 0 + \left. \frac{d \sen \phi }{ d \phi} \right|_{\phi=0} \phi + \ldots   \]


\[ 0 + \left.\cos \phi \right|_{\phi=0} \phi \]

Tenemos:


\[\boxed{ \equiv \phi} \]
