Tenemos:



\[  (F_{2}(q_{i},P_{i},t))= \sum\limits_{i=1}^{n} q_{i}P_{i} + \epsilon G(q_{i},P_{i},t)  \]



\[ p_{k} = \frac{\partial F_{2}}{\partial q_{k}} = \frac{\partial}{\partial q_{k}} \left[ \sum\limits_{i=1}^{n} q_{i}P_{i} +\epsilon G(q_{i},P_{i},t)  \right]   \]


Tenemos:

\[ \boxed{ p_{k} = P_{k} + \epsilon \frac{\partial G}{\partial q_{k}} (q_{i},P_{i},t)  }    \]
