\subsection{Método de Laplace para integrales de la forma $I = \int\limits_{a}^{b} e^{\mu f(x)} dx \quad \mu >> 1 $}


Tenemos:

\[ I \approx \int\limits_{a}^{b} e^{\mu \left[  f(x_{0})+ \frac{d^{2}f(x_{0})}{dx^{2}} (x-x_{0})^{2} \right]}  \]

Donde:

\[ \frac{ df(x_{0}) }{dx} =0    \]


Es decur, $x_{0}$ es el valor donde $f(x_{0})$ es \textbf{máximo}

Tenemos haciendo el camnio de variable:


\[ t=x-x_{0} \]


\[ I \approx e^{\mu f(x_{0})} \int\limits_{a}^{b} e^{-\mu  \left| \frac{d^{2}f}{dx^{2}}  \right|_{x=0}t^{2} } dt   \]



Tenemos:


\[ \boxed{ I \approx e^{\mu f(x_{0})}  \sqrt{  \frac{2\pi}{\mu \left| \frac{ d^{2}f }{dx^{2}}  \right|_{x=x_{0}}}} } \]



 
Ahora podemos usar la aproximación de \textbf{Laplace} en:


\begin{equation}
\begin{split}
Z(T,V,N) &= \int\limits_{ 0 }^{\infty} e^{Ln\Omega - \beta E} dE \\
&= \int\limits_{0}^{\infty} e^{ \frac{1}{k}  \left(  kLn \Omega - \frac{1}{T} E \right) } dE\\
&= \int\limits_{0}^{\infty} e^{\frac{1}{k} \overbrace{ \left(  S-\frac{1}{T} E\right) }^{ S\left[  \frac{1}{T} \right] }}
\end{split}
\end{equation}

Tenemos

\[Z(T,V,N) = N \int\limits_{0}^{\infty}  e^{\frac{N}{k} \left[  S-\frac{1}{T} \right] }  \]


Donde:


\[S= \frac{ S }{N}; \quad e=\frac{E}{N}  \]

EL límite termodinámico es cuando $N \to \infty$; $S \to \infty$, $E \to \infty$


Manteniendo $\frac{ S }{N}=s$ y  $\frac{ E }{N} = e$ finitos

\[ \frac{ d f(x_{0})  }{dx}  \]


Usando aproximación de \textbf{Laplace}:


\[ Z \approx Ne^{ \frac{ N }{K} \left[  S(e_{0}) - \frac{1}{T}e_{0}  \right]  } \sqrt{ \frac{ 2\pi }{ \frac{N}{K} \left|  \frac{ \partial^{2}S\left[ \frac{1}{T}\right] }{\partial e^{2}} \right| }   }   \]


Donde:

\[\left.\frac{\partial}{\partial e} \left[ S(e)-\frac{1}{T} e \right] \right|_{e_{0}} = 0\]



\[ \frac{ \partial S }{\partial e} - \frac{1}{T} =0  \quad \Rightarrow \quad \boxed{ \frac{\partial S}{\partial e} = \frac{1}{T} }\leftarrow \quad \textcolor{Cinnabar}{\textbf{Ecuación de estado}}\]


Además:

\[ \lim\limits_{N \to \infty}  \frac{I}{N} Ln Z = \lim\limits_{N \to \infty} \left\{ \frac{1}{N} \left(  \frac{N}{K}S(e_{0}) - \frac{1}{T}e_{0} \right) +  \cancelto{0}{\frac{1}{N}Ln N} - \left(  \frac{1}{N} \right)\frac{1}{2} \cancelto{0}{Ln \left[ \frac{2\pi }{ \frac{1}{k} \left| \frac{\partial^{2}S\left[ \frac{1}{T} \right] }{\partial e^{2}}\right|N}  \right] }  \right\} \]

\[\lim\limits_{N \to \infty } \frac{1}{N} Ln Z = \frac{1}{K} S(e_{0}) -\frac{1}{T}e_{0} \]

Es decir, en el límite termodinámico:


\[ KLn Z = Ns  -\frac{1}{T} Ne \]

\[ KLnZ=S - \frac{1}{T}E \]

\textcolor{Cinnabar}{\textbf{Conclusión}}:

\[ \underbrace{KLn Z}_{S\left[ \frac{1}{T}  \right]} = S - \frac{1}{T} E \]
