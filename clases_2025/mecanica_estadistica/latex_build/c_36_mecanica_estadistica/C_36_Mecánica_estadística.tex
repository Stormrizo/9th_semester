\subsection{Paramagnetismo cuántico}

En el tratamiento cuántico del paramagnetismo, la energía de interacción entre un momento magnético y un campo externo uniforme \(\mathbf{H}\) está dada por
\[
E_{m} = -\,g\,\mu_{B}\,H\,m,
\]
donde \(\mu_{B}\) es el \textbf{magnetón de Bohr}, definido como
\[
\mu_{B} = \frac{e\hbar}{2mc},
\]
y \(g\) es el \textbf{factor giromagnético} característico de la partícula.

El número cuántico \(m\) toma los valores
\[
m = -j,\, -j+1,\, \ldots,\, j-1,\, j,
\]
donde \(j\) representa el \textbf{momento angular total} (o espín) de la partícula.

\textbf{Interpretación física.}  
Cada partícula con momento angular \(j\) puede orientarse en \(2j+1\) direcciones espaciales distintas con respecto al campo magnético.  
Por ejemplo:
\begin{itemize}
  \item Para el \textbf{electrón} (\(j = \tfrac{1}{2}\)), existen dos orientaciones posibles: \(m = \pm \tfrac{1}{2}\).
  \item Para una partícula de \textbf{espín 1}, hay tres orientaciones: \(m = -1,\,0,\,1\).
  \item Para \(j = \tfrac{3}{2}\), existen cuatro orientaciones: \(m = -\tfrac{3}{2},\,-\tfrac{1}{2},\,\tfrac{1}{2},\,\tfrac{3}{2}\).
\end{itemize}

Estas distintas orientaciones corresponden a \textbf{niveles de energía discretos}, separados por intervalos proporcionales al campo magnético aplicado.  
Así, el campo \(\mathbf{H}\) rompe la degeneración de los estados magnéticos, fenómeno conocido como \textbf{efecto Zeeman}.  
En el contexto del paramagnetismo, esta cuantización del momento magnético permite obtener la magnetización media mediante la estadística de Boltzmann y conduce directamente a la \textbf{ley de Curie} en el límite clásico.


\textit{Una cosa es el spin y otra cosa es el momento angular intrinseco. Si tenemos la propiedad de que la partucka rote entonces la partícula va a generar un campo magnético, entonces debe de existir una relación entre esas cantidades. Debe de existir una cantidad que mapee el spin con el momento intrinseco y precisamente es el factor giromagnético $g$.}

\textit{Esribirmos ahora la función de partición para una partícula. Posteriormente vamos a calcularla para todo el sistema}.


Tenemos:


\textbf{La función de partición} de 1 partícula es:


\begin{equation}
\begin{split}
 z &= \sum\limits_{m=-j}^{j} e^{-\beta E_{m}} = \sum\limits_{m=-j}^{j}  e^{ - \beta \left(  -g\mu_{B}H_{m}   \right) }\\
 &= \sum\limits_{m=-j}^{j} e^{\beta g\mu_{\beta} H_{m}} 
\end{split}
\end{equation}

Definimos $x=\beta g\mu_{B}H$


Tenemos:


\begin{equation}
\begin{split}
z &= \sum\limits_{m=-j}^{j} e^{xm} = \underbrace{e^{-xj}e^{xj}}_{1} \sum\limits_{m=-j}^{j}e^{xm}
\end{split}
\end{equation}


Tenemos:


\[ z=e^{-xj} \sum\limits_{m=-j}^{j} e^{x} (m+j) \]

\[  = e^{-xj} \sum\limits_{k=0}^{2j}  e^{xk} \]

Donde $k=m+j$


Recordemos que:


\[   \sum\limits_{k=0}^{m} = \frac{1-r^{m+1}}{1-r}  \]
Tenemos: 


\[   z = e^{-xj}  \left(   \frac{ 1- e^{ x(2j+1)   }   }{1-e^{x}}    \right)  = \frac{ e^{-xj}  -e^{x(j+1)}  }{1- e^{x}}  \]



\[  z= \frac{  - e^{ - \frac{1}{2}x  } }{ -e^{ - \frac{1}{2}x } } \left(  \frac{  e^{-xj} - e^{ x(j+1) } }{ 1 - e^{x} }  \right) \]


\[  z = \frac{ e^{x (j+1/2) }  - e^{-x (j+1/2)}   }{ e^{\frac{x}{2}} - e^{\frac{x}{2}}  } \]

\textbf{Definición y cambio de variable}
\[
z \;\equiv\; \sum_{m=-j}^{j} e^{x m}
\qquad\Longrightarrow\qquad
k = m + j \;\; \Rightarrow \;\; k=0,1,\ldots,2j
\]
\[
z \;=\; e^{-x j}\sum_{k=0}^{2j} e^{x k}
\]

\textbf{Suma geométrica}
\[
\sum_{k=0}^{n} r^{k} \;=\; \frac{1-r^{\,n+1}}{1-r}
\qquad\text{con}\quad r=e^{x},\; n=2j
\]
\[
z \;=\; e^{-x j}\,\frac{1-e^{x(2j+1)}}{\,1-e^{x}\,}
\]

\textbf{Forma simétrica (funciones hiperbólicas)}
Multiplicamos numerador y denominador por \(e^{-x\left(j+\tfrac12\right)}\) para simetrizar:
\[
z \;=\; 
\frac{e^{-x\left(j+\tfrac12\right)}-e^{x\left(j+\tfrac12\right)}}{e^{-x/2}-e^{x/2}}
\;=\;
\frac{-\,2\sinh\!\left(\left(j+\tfrac12\right)x\right)}{-\,2\sinh\!\left(\tfrac{x}{2}\right)}
\;=\;
\boxed{\;z \;=\; \frac{\sinh\!\left(\tfrac{2j+1}{2}\,x\right)}{\sinh\!\left(\tfrac{x}{2}\right)}\;}
\]

\textbf{Comentarios}
\begin{itemize}
  \item La primera línea de tu borrador debe leerse como \(\displaystyle z=\sum_{m=-j}^{j} e^{xm}\) (faltaba el exponente \(xm\))
  \item La identidad final es la forma estándar que aparece en el tratamiento cuántico del paramagnetismo al sumar sobre los niveles \(m=-j,\ldots,j\)
\end{itemize}


Tenemos:



\[  \boxed{ z=   \frac{ \sen h  \left(  \beta \mu_{B} H_{g} \left(  j+1/2 \right)  \right)  }{  \sen h \left( 1/2 \beta \mu_{B}gH  \right)   } } \]
