En términos del espacio fase clásico (continuo).

Tenemos:

\[ \rho_{gc} (N_{s}, q^{\prime})_{v}, p^{\prime}_{v} ) dq^{\prime}_{v} dp^{\prime}_{v} =  \frac{ e^{ - \beta (H (p^{\prime}_{v}, q^{\prime}_{v}) + \mu_{s} N_{s} ) } }{\Theta (\beta, v,\mu)  } dp^{\prime}_{v} dq^{\prime}_{v}  \]


Donde la función gran canónica se calcula así:

\[ \Theta_{Distinguibles} = \sum\limits_{n=0}^{\infty} \frac{1}{h^{3N}} \int\limits dp^{3N} dq^{3N} e^{- \beta (  H_{N} (q^{\prime}_{s}, p^{\prime}_{s}  )  - N \mu  )  } \]

Tenemos:


\[  \Theta_{Indistinguibles} = \sum\limits_{N=0}^{\infty} \frac{1}{N!h^{3N}} \int\limits dp^{3N} dq^{3N} e^{-\beta  (H_{N} (q^{\prime}_{s},  p^{\prime}_{s} ) - \mu N )  }    \]



Para relacionarlo con cantidades termodinámicas calculamos:



\[S = \langle -K_{B}\ln{ \rho_{gc} } \rangle  \]

Tenemos:


\[ S = \langle -K_{B} \left\{   \ln e^{ -\beta (H - \mu N_{s})  } - \ln \Theta \right\} \rangle_{gc} \quad\text{es decir, es promedio respecto al gran canónico (gc)}  \]


Tenemos

\[  \langle \frac{1}{T} H \rangle - \langle \frac{\mu}{T} N_{s} \rangle + K_{B}\ln \Theta   \]


Tenemos:


\[ S = \frac{1}{T} \langle \underbrace{H}_{U} \rangle - \frac{\mu}{T} \langle N_{s} \rangle + K_{B} \ln \Theta    \]


\[ \Rightarrow K_{B}\ln \Theta (\frac{1}{T}, V, \frac{\mu}{T}  ) = S - \frac{1}{T}U + \frac{\mu}{T} \langle N_{s}\rangle  \equiv S \left[ \frac{1}{T}, \frac{\mu}{T}  \right] \]



O bien en representación energética:



\[  -K_{B}T \ln \Theta (T,V,\mu) = U-TS - \mu \langle N_{S} \rangle \equiv \underbrace{\Phi (T,V,\mu)}_{\text{Potencial gran canónico}}  \]

Notar que:



\[ \Theta(T,V,\mu) = \sum\limits_{N=0}^{\infty} e^{ \frac{\mu  }{K_{B}T} N } Z(T,V,N)  \]

Todavía más; para partículas independientes:



\[ Z(T,V,N ) = \frac{1}{N!}  \left[ Z(T,V,1)   \right]^{N}  \]


\[ \Theta (T,V,\mu) = \sum\limits_{N=0}^{\infty} \frac{1}{N!} \left[  e^{\frac{\mu}{K_{B}T}  } Z(T,V,1)     \right]^{N}   \]


\[= e^{ \left\{  e^{  \frac{ \mu   }{K_{B}T}       } Z(T,V,1)        \right\}     }  \]

Nota:


AL término \[e^{\mu/k_{B}T}\] se le llama fugacidad
 
 \subsection{Ejemplo de otro potencial y su función de partición }



\[  \gamma\left(  \frac{1}{T}, \frac{P}{T}, N  \right) = S - \frac{1}{T}U - \frac{P}{T}V \quad \Rightarrow \quad -T\gamma = U - TS +PV \]


Tenemos:


\[  \bar{\gamma} = \int\limits \sum\limits_{i} e^{  - \frac{1  }{ K_{B}T } U_{i} - \frac{P}{K_{B}T} V  } \Omega(U_{i},V,N) dV    \]



Tenemos:

Si $\left. K_{B}\ln{\bar{\gamma}} = \gamma \right\} \text{Potencial en la entrópica}  $


Entonces:


\[ \underbrace{-K_{B}T\ln{\bar{\gamma}} = \varphi}_{\text{Energética}}  \]

\subsection{Gas ideal (Gran canónico)}

Sabemos que:


\[ Z(T,V,1) = \frac{V}{\lambda^{3}} \quad \text{con}  \lambda = \left( \frac{ h^{2} }{2\pi m K_{B}T}    \right)^{\frac{1}{2}}  \]



También sabemso que para particulas independientes e indistinguibles:


\[    \Theta = \sum\limits_{N=0}^{\infty} \frac{1}{N!} e^{ \frac{ \mu  }{ K_{B}T }N   } \left[  Z(T,V,1)   \right]^{N}       \]

Por lo tanto:

\[ \Theta = exp \left\{ e^{\frac{ \mu }{K_{B}T  }} \frac{ V  }{\lambda^{3}}    \right\} = exp\left\{  e^{  \frac{ \mu }{K_{B}T  }  } V \left(  \frac{2\pi K_{B}T  }{h^{2}}  \right)^{\frac{3}{2}} \right\}    \]



El potencial gran canónico es:




\[ Phi(T,V,\mu) = -K_{B}T \ln \Theta = -K_{B}Te^{ \frac{ \mu }{K_{B}T}  } V \left( \frac{2\pi m K_{B}T}{h^{2}}   \right)^{ \frac{3}{2} } \]





Las ecuaciones de estado son:



\[   - \frac{  \partial \phi }{ \partial T }  = S(T,V,\mu) = e^{\frac{\mu}{K_{B}T}  } VK_{B} \left(  \frac{ 2\pi mK_{B}T }{h^{2}}    \right)^{ \frac{3}{2} } \left(   \frac{5}{2} - \frac{\mu}{K_{B}T}    \right)   \]



Tenemos:


\[   - \frac{  \partial \phi  }{\partial V} = P(T,V, \mu) = K_{B}T e^{ \frac{ \mu  }{K_{B}T}  }  \left( \frac{ 2\pi mK_{B}T }{h^{2} }  \right)^{\frac{3}{2}}      \]


\textbf{NOTA}:


Como:



\[  -K_{B}T\ln\Theta = U -TS - \mu{N}  \]

Usando la relación de Euler ($U=TS-PV+\mu{N} $)


\[ -K_{B}T \ln \Theta = ( TS-PV+\mu N ) -TS -\mu N   \]



\[ \Rightarrow  \quad \boxed{  \ln{\Theta} )= \frac{PV}{K_{B}T}    }  \]


Por eso alguns veces se le llama el \underline{potencial PV}


\subsection{ Fluctuaciones del gran canónico  }


Tenemos:



\[ \rho_{i,N}  =  \frac{ e^{ -\beta (E_{i} - \mu{N}) }  }{  \Theta }   \]


 O bien:
 
 
 
 \[  \rho_{E,N} = \frac{ \Omega_{N}(E) e^{  -\beta (  e-\mu{N} ) }   }{  \Theta }         \]
 
 
 
 El número más probable de partículas, es el está en el máxima de $P_{E,N}$ 



Para encontrarlo derivamos e igualamos a cero.



\[  \frac{\partial }{\partial N}  \ln \rho_{E,N} = \frac{  \partial  }{\partial N}  \left[  \ln \Omega_{N}(\epsilon) + \frac{\mu}{K_{B}T}N  \right]_{ N=N^{\ast} } =0 \]





\[  \Rightarrow \quad \frac{  \partial }{\partial N} K_{B}\ln \Omega_{N^{\ast}}(E) = - \frac{\mu}{T}   \]



\[  \Rightarrow \quad  \underbrace{ \frac{\partial }{\partial N}   S(E,V,N^{\ast}) = - \frac{\mu}{T}}_{\text{Ec. de estado que me indica el valor más probable de $N$ en $N^{\ast}$ }}  \]

Por otro lado, podemos calcular el promedio:



\[  \langle N \rangle = \sum\limits_{i,N} N \rho_{i,N} = \sum\limits_{i,N}  \frac{ N }{\Theta} e^{  -\beta (E_{i}  - \mu N )  } = \frac{\partial }{\partial \mu} K_{B}T \ln \Theta = - \frac{  \partial \Phi }{\partial \mu } \]


Es decir:



\[   \underbrace{-\frac{ \partial \Phi   }{\partial \mu} = \langle N \rangle}_{ \text{Ec. de estado en Gran Canónico} }   \]
