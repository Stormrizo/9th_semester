\section{Modelo de Sommerfield: Dependencia de la temperatura}


LOs electrones son ferminiones, por lo que podemos usar la estadística de Fermi-Dirac: 


\[ f(\epsilon) = \frac{1}{ e^{( \epsilon - \mu  )/ K_{B}T +1}      }  \]



\[ \mu = \text{potencial químico} \]


Cuál es la probabilidad de ocupación el nivel de energía $\epsilon$ cuando el sistema se encuentra a una temperatura $T$

Ocurre que para electrones:


\[ \lim\limits_{T \to 0 }  \mu = \epsilon_{f}  \]


EL potencial químico está relacionado con el cambio de partículas en un sistema. El potencial químico no tiene una interpretación. 

Tenemos:

\[  \boxed{ \text{Para un gas de electrones, su potencial químico a $T=0$ es el nivel de Fermi} }  \]


Sabemos que:



\[ N = \int\limits f(\epsilon) g(\epsilon)d\epsilon \]


Usando (1) y (2) para determinar la densidad de partículas:

\[  n = \frac{N}{V} = \frac{1}{V} \int\limits f(\epsilon)   \]


$\uparrow$ está en las notas, las comparte más tarde en teams.




Tenemos la integral:

Analicemos a $T=0 ^{\circ}K$:


\[ f(\epsilon) =  \left\{ \begin{array}{l}
1 \quad 0< \epsilon<\epsilon_{f}\\
0 \quad \epsilon>\epsilon_{f}
\end{array}\right.   \]


Entonces:


\[ n = \text{Número de electrones por unidad de volumen de la muestra} \]



Entonces:



\[  k_{f} = \text{Número de onda asociado a la energía de último nivel de Fermi} \]


Tenemos:

\[ n = \frac{N}{V} = \frac{1}{2\pi^{2}} \left( \frac{2m}{\hbar^{2}}   \right)^{\frac{3}{2}} \int\limits \frac{ \epsilon^{\frac{1}{2}}  }{  e^{  (\epsilon - \mu) } /K_{B}T + 1   } d\epsilon  \]





Para un gas de electrones el potencial químico es el nivel de Fermi a temperatura $T$. 


 La integral es del tipo de integrales de Fermi-DIrac: 


\[F_{j}(y_{0})  = \int\limits_{0}^{\infty}   \frac{ y^{j}  }{  e^{y-y_{0}}  +1}  dy    \]


Una solución aproximada converge cuando $y_{0}>>1$, entonces:



\[ F_{j}(y_{0}) = \frac{ y_{0}^{j+1}  }{j+1}  \left[ 1 + \frac{ \pi^{2}j(j+1)  }{6y_{0}^{2}}  + \ldots + \right] \]




EN metalees, usualmente $T<<T_{f}$ y $K_{B}T \approx 0\text{.}01\mu$, así que se cumple que:


\[  y_{0} =  \frac{\mu}{K_{B}T}>> 1   \]



\textbf{Tarea}:



\[  y_{0} = \frac{\mu}{K_{B}T} \]


\[ y= \frac{\epsilon}{K_{B}T}; \quad j = \frac{1}{2}\]




\[ dy = \frac{d\epsilon}{K_{B}T}  \]



Realizar este cambio de variable y llegar a:


\[ n \approx \frac{1}{3\pi^{2}} \left(  \frac{2m}{\hbar^{2}}  \right)^{\frac{3}{2}} \left[  1 + \frac{\pi^{2}}{ 8 \left(\frac{\mu}{K_{B}T}   \right)^{2} } \right]  \]

EL resultado anterior se igual al número de electrones por unidad de volumen.
