\section{Clase de hoy: Electrones bajo un potencial periódico \underline{débil}}

Tenemos:

\[  - \frac{\hbar^{2}}{2m} \frac{d^{2}\psi}{dx^{2}} + V(x) \psi = \epsilon \psi  \]


Tenemos:

\[ \psi \to \psi_{\vec{k}}(x) \]

\[ k_{0}^{2} \equiv \frac{2m\epsilon}{\hbar^{2}}; \quad \text{y} \quad - \frac{2m}{\hbar^{2}} V(x) 0 \underbrace{\gamma}_{\text{parámetro}} f(x) \]

Dependiendo del valor de gamma nos modula la intensidad del potencial en algún momento. 

Tenemos: 

\[ \ddot{\psi}(x) + \left[ \gamma f(x)   + k_{0}^{2}\right] \psi(x) =0 \]


Consecuencia de la periodicidad podemos definir una expansión en \textbf{serie de Fourier}:


\[ f(x) = \sum\limits_{s=-\infty}^{\infty} C_{s} e^{-ik_{s}x} \]


Tenemos:


\[ K_{s} = \frac{2\pi s}{a}, \quad s\in \mathbb{Z} \]

Con:


\[ C_{s} = \int\limits f(x) e^{ik_{s}x}dx \]

Integramos en un periodo de la función. 


\[ C_{s} = \int\limits_{0}^{a} s f(x) e^{ik_{s}x}dx \]


Tenemos:


\[ V_{s} = - \frac{ \hbar^{2} }{2m} \gamma C_{s} \]

Vamos relacionando todo lo que tenemos hasta ahora, tenemos también nosotros lo siguiente:


Tenemos un potencial periódico. 


Del teorema de \textbf{Bloch}:


\[  \psi (x) = u(x) e^{ikx}  \]

Con:


\[  u(x) = u(x+a) \]


Como serie:

\[ u(x) = \sum\limits_{n=-\infty}^{\infty} b_{n}e^{-ik_{n}x}, \quad k_{n} = \frac{2\pi n}{a}, \quad n \in \mathbb{Z} \]




Tenemos:

\[ \psi = \sum\limits_{n=-\infty}^{\infty} b_{n}e^{ik_{n}x} e^{ikx} = e^{ikx}\sum\limits_{n=-\infty}^{\infty} b_{n}e^{-ik_{n}x} \]

Entonces ya tenemos una función de onda que prodríamos sustituirla para resolver la ecuación de segundo orden. Vamos agregar un segundo detalle. 

Nosotros sabemos cual debe de ser la solución para partícula libre:


\[ \psi(x) =b_{0}e^{ik_{0}x} \]


Donde:


\[ k_{0}^{2} \equiv \frac{2m\epsilon}{\hbar^{2}} \]


\textbf{Proponemos}: Una función de onda que tenga de manera general:

\[  \psi(x) = b_{0}e^{ikx} + \gamma \left[  e^{ikx} \sum\limits_{n\neq 0} b_{n} e^{-ik_{n}x}\right] \]

Cuando $\gamma$ es cero son queda un solución para \underline{partícula libre}.

Esta anterior la sustituimos acá:

\[ \ddot{\psi}(x) + \left[ \gamma f(x) + k_{0}^{2} \right] \psi =0 \]

Tenemos:

\[ -k^{2}b_{0}e^{ikx}+\gamma e^{ikx}\sum\limits_{n\neq 0} b_{n}e^{-ik_{n}x} (k-k_{n})^{2} + \left[ \gamma f(x) + k_{0}^{2}   \right]\left[ b_{0}e^{ikx}+\gamma e^{ikx}\sum\limits_{n\neq 0}b_{n}e^{-ik_{n}x} \right] =0\]



Tenemos:


\[ - k^{2}b_{0}+\gamma \sum\limits_{n\neq 0} b_{n}e^{-ik_{n}x} \left\{  (k-k_{n})^{2}+k_{0}^{2}  \right\} + \gamma^{2} f(x)\sum\limits_{n \neq 0} b_{n}e^{-ik_{n}x}  + \gamma f(x)b_{0}+k_{0}^{2}b_{0}=0 \]

Tenemos:


\[ b_{0} (k_{0}^{2}-k^{2}) + \gamma \left\{ f(x) b_{0} + \sum\limits_{n\neq}b_{n}e^{-ik_{n}x} \left\{ k_{0}^{2} - (k-k_{n})^{2}\right\}\right\} + \underbrace{\gamma^{2}f(x) \sum\limits_{n\neq 0} b_{n}e^{-ik_{n}x}}_{A}  =0\]



Donde:

\[ \epsilon = \frac{\hbar^{2}k_{0}^{2} }{2m} \]


Tenemos $V(x)$ débil, entonces $\gamma$ es pequeña.

Tenemos:


\[  - \frac{2m}{\hbar^{2}} V(x) = \gamma f(x)  \]


SI el potencial es intenso, entonces $\gamma$ es considerable.

Vamos a trabajar algebraicamente con un caso que si podamos resolver, que si el potencial es pequeña, entonces podemos despreciar esos ordenes.

En el examen tendríamos que resolver toda la expresión considerando la parte que ahora vamos a despreciar, es decir tendríamos que considerar también el término $\boldsymbol{A}$.

\subsection{Resolviendo}


Vamos a resolver:


\[ b_{0}(k_{0}^{2}-k^{2}) + \gamma f(x)b_{0}+ \gamma \sum\limits_{n\neq 0} \left[  k_{0}^{2} - (k_{n}-k)^{2}  \right] b_{n}e^{-ik_{n}x} =0\]

Tenemos:


\[  f(x) = \sum\limits_{s=-\infty}^{\infty} C_{s}e^{-ik_{s}x} = C_{0}e^{-ik_{s=0}x} + \sum\limits_{s \neq 0} C_{s}e^{-ik_{s}x} = C_{0} + \sum\limits_{s \neq 0} C_{s} e^{-ik_{s}x} = \sum\limits_{n \neq 0}C_{n}e^{-ik_{n}x} \]


Donde:

\[  K_{s=0} = \frac{2\pi s}{a} = 0 \]
 
Podemos elegir por conveniencia que el potencial valga \textbf{cero}.  

Entonces: 

\[ \cancelto{0}{C_{0}} \]

Tenemos:



\[ \Rightarrow \quad b_{0}( k_{0}^{2} - k^{2}) + \gamma \left\{ \sum\limits_{n\neq 0} b_{0}C_{n}e^{-ik_{n}x} + \sum\limits_{n\neq 0} b_{n}e^{-ik_{n}x} \left[  k_{0}^{2}-(k_{n}-k)^{2}  \right]   \right\}  \]


Multiplicamos todo por:


\[ e^{ik_{m}x}, \quad m \in \mathbb{Z}\, \text{arbitrario} \]

e integrar en una celda.

Escencialmente los términos $C_{0}$ de la serie están relacionados con el potencial.


Tenemos:


\[  \int\limits_{0}^{a} (k_{0}^{2} - k^{2}) e^{ik_{m}x} dx + \gamma \int\limits_{0}^{a} \sum\limits_{n\neq 0} b_{0}c_{n}e^{-ik_{n}x} e^{ik_{m}x} dx + \gamma \int\limits_{0}^{a} \sum\limits_{n\neq 0} b_{n} \left[  k_{0}^{2} - (k_{n}-k)^{2}  \right]e^{-ik_{n}x}e^{ik_{m}x} dx=0   \]



Tenemos:

\[ e^{i k_{m}x} = e^{i  \frac{2\pi mx}{a} } \]


\[  \int\limits_{0}^{a} b_{0} (k_{0}^{2} - k^{2})e^{ik_{m}x}dx  \quad \to \quad \int\limits_{0}^{a} e^{ik_{m}x} dx = \left. \left( \frac{1}{ik_{m}} \right) e^{ik_{m}x} \right|_{0}^{a}  =\left.  \frac{ a  }{i 2\pi m} e^{ik_{m}x}\right|_{0}^{a}  \]


\[ k_{m} = \frac{2\pi }{a} m, \quad m \in \mathbb{Z}, \quad \left\{ \begin{array}{cc}
0 & m \neq 0\\
a & m=0
\end{array} \right. \]

Es decir:


\[ \left(  \frac{a}{ i2\pi m }  \right) \left[  e^{ i\frac{2\pi m}{a} a} - \cancelto{1}{ e^{i \frac{2\pi m}{a}(0)  }   }  \right]  \]


\[ = \left(   \frac{a}{i 2\pi m  } \right)(0) \]


Tenemos:


\[ \int\limits_{0}^{a} e^{i_{m}x} dx = \int\limits_{0}^{a} dx = a   \]


Tenemos:


\[  \int\limits_{0}^{a} e^{i (k_{m}-k_{n})x }dx = \left. \frac{1}{ i (k_{m}-k_{n})   } e^{i (k_{m}-k_{n})  x} \right|_{0}^{a}  = \frac{  e^{ i (k_{m} - k_{n})a } -1 }{ i ( k_{m} - k_{n} )  } =   \left\{ \begin{array}{cc}
0 & m \neq n\\
a & m=n
\end{array} \right.  \]

\[ k_{m} - k_{n} = \frac{ 2\pi (m-n)   }{a}  \]
